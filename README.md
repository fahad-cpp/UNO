# UNO
A terminal Uno game made in C++.<br> this is supposed to be an object oriented port of my 2 years old Uno terminal game in C

# Setting up
Clone the repo
```batch
git clone https://github.com/fahad-cpp/UNO UNO
```

Build using CMake
```batch
cd UNO
mkdir build
cd build
```
```batch
cmake ..
cmake --build .
```
